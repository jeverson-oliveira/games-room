❓ Sobre o GAMER.IO

Games Room — catálogo de jogos free-to-play

O projeto

Este é um front-end em Angular 20 que consome a API pública FreeToGame. Navegue por Jogos, veja os Em Alta (ordenados por popularidade), salve preferências em Configurações e explore detalhes de cada título.

Stack

  • Angular 20 + Standalone + Signals
  • RxJS 7 + HttpClient + interceptors
  • Control flow @for/@if
  • SCSS neon theme (Orbitron)

API

  • GET /api/games — lista
  • GET /api/games?platform=pc
  • GET /api/games?category=mmorpg
  • GET /api/games?sort-by=popularity
  • GET /api/game?id=452 — detalhe

Proxy dev: proxy.conf.json → https://www.freetogame.com
